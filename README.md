# Математичка авантура — 2. разред

Интерактивна PWA игра за вежбање математике у другом разреду.

## Покрени игру

👉 **[Отвори Математичку авантуру](https://mkmelektro.github.io/VezbanjeMatematike2OS/)**

Скенирај QR код телефоном:

![QR код за покретање игре](VezbanjeMatematike2OS_QR.png)

## Инсталација на Android

1. Отвори линк изнад у Chrome-у.
2. Отвори мени **⋮**.
3. Изабери **Install app** / **Add to Home screen**.
4. После првог учитавања игра може да ради и offline.

## Шта садржи

- сабирање и одузимање за други разред;
- вертикални приказ рачунања;
- препознавање рукописа;
- унос тастатуром;
- помоћну таблу за рачунање;
- тежи ниво и маратонац са наградама;
- једна чоколадица на сваких 30 тачних одговора;
- fullscreen режим;
- offline рад као PWA.
